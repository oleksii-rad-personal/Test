# threads-recap

Скіл збирає активність за день і пропонує **2–3 варіанти поста для Threads**,
які користувач копіює вручну. Публікацію робить сам користувач — інтеграції з
Threads немає, тому **не намагайся постити автоматично**.

## Кроки

### 1. Зібрати сирий матеріал (детермінований дайджест)

Запусти скрипт (він лише читає, нічого не змінює):

```bash
python3 "$CLAUDE_SKILL_DIR/scripts/recap.py"
```

Якщо `$CLAUDE_SKILL_DIR` не заданий, використай шлях до цієї теки скіла
(`.../.claude/skills/threads-recap/scripts/recap.py`). За потреби додай
`--date YYYY-MM-DD` (за замовчуванням — сьогодні).

Прочитай Markdown-дайджест: проєкти/гілки, мої запити (теми), інструменти, коміти
та секцію `Meta`.

### 2. Додаткові джерела (якщо конектори підключені)

Якщо в сесії доступні відповідні MCP-інструменти — підтягни помітну **сьогоднішню**
активність, щоб пост був повнішим:

- **Gmail:** пошук листів за сьогодні (напр. `search_threads` з `newer_than:1d`
  або `after:<дата>`), лише теми/суть, без цитування приватного вмісту.
- **Slack:** свої сьогоднішні повідомлення/треди, якщо інструмент є.

Якщо конекторів немає — просто пропусти цей крок. **Не вигадуй** активності,
якої немає в даних.

### 3. Врахувати обсяг даних

Якщо в `Meta` видно лише одну сесію (ознака веб-середовища / ефемерного
контейнера) — коротко попередь користувача, що бачиш обмежений зріз дня, і що
для повної картини скіл краще запускати локально. Все одно згенеруй пост із
наявного.

### 4. Скласти варіанти поста

Зроби **2–3 варіанти** для Threads:

- **Мова:** українською (за замовчуванням), від першої особи, casual, дружній тон
  «Хей, дивіться що я...». Якщо користувач попросив іншу мову — використай її.
- **Довжина:** кожен варіант ≤ 500 символів (ліміт Threads).
- **Емодзі:** доречні, помірно.
- **Різні кути** між варіантами, наприклад:
  1. «Що навчився сьогодні» — інсайт/висновок дня.
  2. Технічна деталь — конкретна річ, яку зробив/розібрав.
  3. Короткий підсумок «сьогодні: X, Y, Z».
- **Приватність:** без імен клієнтів, секретів, внутрішніх шляхів чи вмісту
  листів/чатів. Тільки те, чим не соромно поділитися публічно.

### 5. Вивести результат

Покажи варіанти чітким пронумерованим списком (по одному блоку на варіант),
щоб зручно було скопіювати. Нагадай, що публікація — вручну в Threads.

## Локальне встановлення (глобально)

Щоб скіл був доступний у всіх проєктах локально, а не лише в цьому репозиторії,
скопіюй або залінкуй теку в `~/.claude/skills/`:

```bash
cp -r .claude/skills/threads-recap ~/.claude/skills/
```
